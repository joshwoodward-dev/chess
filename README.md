# Chess

A chess game (and eventually a bot) built alongside Skillgap. Vue 3 + TypeScript + Vite, tested with Vitest.

## Setup

```sh
npm install
npm run dev        # start the dev server
npm run test:unit  # run tests in watch mode
npm run type-check
npm run lint
```

## Layout

- `src/engine/` – game logic (pure TypeScript, no Vue)
- `src/components/` – UI components
